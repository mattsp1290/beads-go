# v0.1.0 Release Checklist

Use this checklist when cutting the first public beads-go release.

## Before Tagging

- Run the full local verification suite from the repository root:
  - `go mod tidy --diff`
  - `go vet ./...`
  - `golangci-lint run ./...`
  - `golangci-lint fmt --diff`
  - `go test -race ./...`
  - `go test -tags=integration ./...`
- Confirm the GitHub Actions unit and integration jobs pass on the release
  branch.
- In `~/git/local-symphony`, verify the temporary replacement still passes:
  - `replace github.com/mattsp1290/beads-go => ../beads-go`
  - `go test ./internal/tracker/beads ./test/conformance/tracker`
  - `go test ./...`
- Update `CHANGELOG.md` by moving relevant `Unreleased` entries under a
  `v0.1.0 - YYYY-MM-DD` section.

## Tagging

- Ensure the release commit is clean and includes the changelog update.
- Create and push the tag:
  - `git tag v0.1.0`
  - `git push origin v0.1.0`

## After Tagging

- Update local-symphony to consume the tagged module:
  - replace `require github.com/mattsp1290/beads-go v0.0.0` with `v0.1.0`
  - remove `replace github.com/mattsp1290/beads-go => ../beads-go`
  - run `go mod tidy`
  - rerun `go test ./internal/tracker/beads ./test/conformance/tracker`
  - rerun `go test ./...`
- Verify pkg.go.dev indexes the release:
  - `https://pkg.go.dev/github.com/mattsp1290/beads-go@v0.1.0`
- If pkg.go.dev has not indexed the tag yet, request it with:
  - `GOPROXY=proxy.golang.org go list -m github.com/mattsp1290/beads-go@v0.1.0`
- Confirm `README.md` and `CHANGELOG.md` still match the published module
  version and bd npm pin.
